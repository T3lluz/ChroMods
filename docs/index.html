ChroMods

Chromium theming mods

Theming mods for the sites you keep open, adapted from my-internet. One command installs it, and the same command updates it.

    Install

    curl -fsSL https://raw.githubusercontent.com/T3lluz/ChroMods/main/install.sh | bash
    1. Run the command. It downloads ChroMods, copies the folder path to your clipboard, and opens the extensions page.
    2. Turn on Developer mode, top right.
    3. Click Load unpacked and paste the path.

    Update

    The popup checks GitHub every few hours and badges the toolbar icon when a new version lands. Chromium cannot auto-install an unpacked extension, so updating is two steps:

    Re-run the install command above, then open the popup and hit Settings → Updates → Reload ChroMods. That re-reads the folder from disk and refreshes your themed tabs.

    Prefer to do it by hand? Clone the repo or grab a release ZIP and load that folder unpacked. Set CHROMODS_DIR before running the installer to put it somewhere else.
