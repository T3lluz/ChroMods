Update ChroMods

Checking the download…

Chromium can't overwrite an unpacked extension by itself. Pick the folder you loaded (the installer uses ~/.chromods or %LOCALAPPDATA%\ChroMods), and ChroMods writes the new files then reloads.

Use a terminal instead
curl -fsSL .../install.sh | bash

Then return to the popup and hit Reload ChroMods. Hidden folders: show hidden files in the picker if you installed to ~/.chromods.
